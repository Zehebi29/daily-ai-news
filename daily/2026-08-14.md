# 2026-08-14 AI资讯（周五·工具实测推荐）

## 1️⃣ Gemini 3.7 Flash：编码和 Agent 能力大涨，但明年 1 月价格翻倍
谷歌发布 Gemini 3.7 Flash，主打编码和长流程 Agent。FrontierCode 1.1 Main 从 34.4% 涨到 43.6%，DeepSWE v1.1 从 49% 冲到 65.3%。提供 low/medium/high 三档思考强度。促销价 $0.75/百万输入 + $3.75/百万输出，明年 1 月 1 日翻倍到 $1.50/$7.50。HN 656 分。
- 来源: [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/) | [HN 656pts](https://news.ycombinator.com/item?id=49289112) | [TNS分析](https://thenewstack.io/gemini-3-7-flash-agents/)

## 2️⃣ GPT-5.6 Sol Ultrafast：Cerebras 把推理速度拉满，比 Fable 5 快 11 倍
OpenAI 与 Cerebras 推出 GPT-5.6 Sol 的 Ultrafast 模式，由 Cerebras 芯片驱动，输出速度比 Claude Fable 5 快 11 倍、比 Opus 4.8 Fast 快 5 倍。2500 道博士级难度题实测：Ultrafast 11 小时 11 分钟答完，Fable 5 用了 78 小时 27 分钟。先在 OpenAI API 小范围开放。HN 463 分。
- 来源: [Cerebras Blog](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai) | [HN 463pts](https://news.ycombinator.com/item?id=49289844)

## 3️⃣ Zed 发布 Delta：多人一起审 Agent 写的代码
Zed 发布 Delta（私测中），多人协作环境：DeltaDB 把对话和代码工作区实时同步给线程内所有人，评论直接钉在代码上。可连接 Claude Code 等第三方 harness，网页版是同一个 Rust 程序编译成 WebAssembly，无需安装。HN 662 分。
- 来源: [Zed Blog](https://zed.dev/blog/introducing-delta) | [HN 662pts](https://news.ycombinator.com/item?id=49276574)

## 4️⃣ DeepSeek 开源 Agent 框架 Harness：模型、工具、循环全都能换
DeepSeek 开源 Agent 框架 Harness（MIT 协议，开发者预览版）：模型适配器、工具注册表、Agent 主循环全部是可插拔插件。想换模型、换工具、改 Agent 跑法都不用动核心代码。HN 579 分。
- 来源: [The New Stack](https://thenewstack.io/deepseek-harness-open-source-plugins/) | [HN 579pts](https://news.ycombinator.com/item?id=49285244) | [DeepSeek Harness](https://deepseek.com/harness/en/)

## 5️⃣ Suno Studio 2.0：从 AI 玩具往正经音乐工作站靠拢
Suno Studio 2.0 发布：加入用户呼声最高的 MIDI 支持、效果器插件和合成器，向正经 DAW（数字音频工作站）靠拢。同时加了聊天机器人，说一句想要什么效果就自动配置，降低上手门槛。
- 来源: [The Verge](https://www.theverge.com/ai-artificial-intelligence/979345/suno-studio-2-0-midi-chatbot-custom-effects)
