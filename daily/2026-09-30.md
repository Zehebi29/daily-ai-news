1. **Livenerf：给「模型被偷偷降级」判案的开源基准，昨晚起就是 HN 第一（718 分 / 279 评论）** — 一个 deliberately boring、append-only 的小基准，只回答一个问题：模型发布后会不会悄悄变差。以 Claude Opus 5.5 发布日 2026-09-22 为第 0 天，跑在 Claude Max 订阅 + headless Claude Code（`claude -p`，不用 API key）上，每天 90 个样本；思路是「模型本身没法确定性化（采样参数没了、thinking 也关不掉），那就把其它一切确定化」：冻结 prompt、锁 CLI（2.1.280）、固定 grader、原始日志永久保留，再靠几千个样本做统计漂移检测。框架用英国 AISI 的 Inspect，统计口径直接照 Anthropic 自己的《Adding Error Bars to Evals》，避免「自研统计」被吵架。截至 9/29：30 天里已收 6 天（基线 6/10）、一天不漏，全部跑在同一个 harness hash（`461391b6fce64167`）上；前 10 天为基线，之后两个 10 天窗口，第一次下结论大约在 10/24，首行 Results 在 day 20 之后。作者对假设保持中立——量化、同名换小模型、降 effort、改路由都可能，也可能什么都没发生。[GitHub](https://github.com/ninjahawk/livenerf) · [HN](https://news.ycombinator.com/item?id=49901736)

2. **OpenAI DevDay 两件大事：常驻 agent「Dots」只给 Pro/企业版，GPT-6.1 Sol 七天就把 GPT-6 Sol 换掉了** — ①Dots 是 always-on agent，不绑硬件和界面，后台持续追用户设定的目标；主 dot 可命名，OpenAI 的设想是「以后是一队 dot 替你干活」；可从 ChatGPT 或 Codex 启动，用 Slack、Teams 对话（短信后续支持），每个 dot 能单独配身份、凭证和工具，正在和微软对接 Agent 365 安全管控。可用范围很窄：只有 Pro 与 Business Premium 的合格市场用户，Free/Go/Plus 都没有。②GPT-6.1 Sol：AA 今天发文确认，Intelligence Index 距 GPT-6 Astra 只差 1 分，但 max effort 下每任务 $0.72 vs Astra 的 $3.26；标价与 GPT-6 Sol 同为 $2/$10 每百万 token，但缓存读折扣从 90% 提到 95%，agentic 负载混合价更低。相对 GPT-6 Sol：Terminal-Bench 4.0 +12 分、HLE +5、GDP.pdf +6、AA-Omniscience 准确率 +8 且幻觉率 60%→54%；代价是输出 token 多 10–30%（低/中 effort 在 token 效率上仍是 Pareto 最优）。[TC Dots](https://techcrunch.com/2026/09/29/openai-launches-dots-its-bubbly-agentic-avatar/) · [HN Dots 664pts](https://news.ycombinator.com/item?id=49896604) · [AA GPT-6.1 Sol](https://artificialanalysis.ai/articles/gpt-6-1-sol-replaces-gpt-6-sol-after-just-7-days-with-near-astra-intelligence)

3. **OpenClaw Enterprise 开源：TNS 说它是「agent 的 Kubernetes」，Red Hat 和 NVIDIA 一起做的** — 今天 TNS 报道 + OpenClaw 博客（9/29）：OCE 是 agent 的企业级控制平面，多租户 + 硬安全边界 + 覆盖 agent 生命周期的治理与审计，且 harness、模型、沙箱这些核心原语都能换成第三方或内部实现。来历值得注意：项目最初起于 OpenAI，随后捐给 OpenClaw Foundation 成为独立项目，再与 Red Hat、NVIDIA 共同开发；Red Hat 与 OpenAI 内部都在试点——OpenAI 已经让 agent 拿着代码库和插件的完整权限在跑。官方定位还是「内部 pilot 可用」：1.0 之前就开源、docker-compose 本地跑、k8s 内部部署，任何机构永久免费用；安全是首要目标（可信/不可信负载硬隔离 + 沙箱 + LLM 审查 + 细粒度权限），过几周会发参考架构。[TNS](https://thenewstack.io/openclaw-enterprise-kubernetes-agents/) · [OpenClaw](https://openclaw.ai/blog/openclaw-enterprise)

4. **Pi 反转：当年公开声明「不支持 MCP」，现在把 MCP 放进了核心（HN 今天 210 分 / 89 评论）** — pi.dev 上那句自豪的「Pi does not support MCP」已经被推翻，Earendil 工程博客今天解释了原因：一是 MCP 本身一年里变了；二是让 MCP 进核心需要的那套改造本身有用——顺带让 Jev 在 Pi 里更好用，因为 Pi 要的东西和 MCP 要的很像：一个可以玩的解释器沙箱。实现上是把 MCP 工具暴露给 JavaScript 沙箱（和 Codex 等 harness 一样的做法）。他们仍不留情面地批 MCP 最大问题依旧是难组合（即使有 codemode 这个小沙箱也不够），问题更多在 MCP server 和各家 harness 的做法；主张 MCP 应该更接近「OpenAPI + 智能工具发现」——工具返回结构化数据，靠文档和描述被发现，而不是把一堆工具直接倒进上下文里优化自己的 token。[Earendil](https://earendil.com/posts/you-said-no-mcp/) · [HN](https://news.ycombinator.com/item?id=49906637)
