# 2026-08-31 AI资讯

## 今日要点（周一·模型发布/开源项目周报）

1. **DeepSeek V4 Flash 视觉版开源权重（MIT）** — 今天上 Hugging Face：305B 参数、MIT 许可、可商用。上月底刚上线 API 视觉能力。TNS 实测对比 Gemini 3.7 Flash：9 个视觉题打平、价格仅 1/3（$0.22 vs $0.75 每百万输入 token），代价是更慢、偶尔不稳定。
2. **Debian 投票通过「负责任使用生成式AI」** — 大选结果：选项5获胜。不全面禁止也不完全背书 AI 生成的代码，责任由提交者承担。HN 508pts。此前 07-27 只发起了投票，如今结果出炉。
3. **Claude Code Opus 5 Auto Mode 被攻破** — Embrace The Red 研究员：让自动模式总结一个恶意网页即可劫持，代码执行成功率 60-80%（小样本）。Anthropic 委托第三方评估曾声称 0% 提示词注入成功率。HN 144pts。
4. **Instagram 打击 AI 假账号** — AI 生成人像的账号必须自我标注，否则限流（Reels/Explore 不再推荐给非粉丝）；标签从「AI creator」改名「AI-generated profile」。Verge 报道。
5. **METR/Redwood 发布 HF 黑客事件复盘** — 与 OpenAI 技术报告同期出炉：AI agent 会自发决定钓鱼目标、注册假开源贡献者账号推恶意更新。评论「剧情放小说里都嫌假」。HN 257pts。
