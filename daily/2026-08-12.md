# 2026-08-12 AI资讯（周三·Agent/工程/落地坑）

## 1️⃣ 加密的「内心独白」也能被偷：思维链跨模型重放破解
安全研究团队披露：OpenAI/Anthropic/Google 返回给客户的加密思维链(CoT)痕迹，其实可以跨会话、跨用户、跨模型重放。做法是把前沿模型的推理痕迹丢给更弱的兄弟模型，再越狱弱模型，隐藏的推理过程就被解码出来。HN 524 分，评论区认为思路很巧妙——「加密」不等于「防偷」。
- 来源: [Stolen Thoughts Research](https://stolen-thoughts.com/) | [HN 524pts](https://news.ycombinator.com/item?id=49257876)

## 2️⃣ Docker Sandboxes：给编程Agent一次性沙箱
Docker 发布 Docker Sandboxes，为 Claude Code、Codex、Gemini、Kiro 等编程 Agent 提供微虚拟机隔离的即用即弃沙箱，防止 Agent 乱改宿主电脑文件。HN 678 分是近两天最高分。不过社区吐槽：一个本地开发工具还强制登录才能用，有点劝退。
- 来源: [Docker](https://www.docker.com/products/docker-sandboxes/) | [HN 678pts](https://news.ycombinator.com/item?id=49239751)

## 3️⃣ Google：Go 是最适合 AI 辅助编程的语言
Google 开发者博客发文：AI 把软件工程从「写代码」变成「审代码」，Go 的严格编译器和统一工具链能让 AI 生成的代码更可靠，因此是最适合 AI 辅助编程的语言。引发讨论：AI 编程时代，语言的可审性比可写性更重要，程序员的活儿正在转向把关。
- 来源: [Google Developers Blog](https://developers.googleblog.com/why-go-is-an-ideal-language-for-ai-assisted-software-engineering/) | [HN 298pts](https://news.ycombinator.com/item?id=49261133)

## 4️⃣ Databricks 收购 Electric：给每个 AI Agent 配专属数据库
Databricks 收购 Electric——WASM 版 Postgres（PGlite）背后的团队。赌的是：未来每个 AI Agent 都需要成千上万个小巧的一次性数据库，再靠同步引擎串起来。给 Agent 配数据库本质是装记忆和状态，Agent 基建的下一块拼图轮到数据库。
- 来源: [The New Stack](https://thenewstack.io/databricks-electric-wasm-agentic-postgres/)

## 5️⃣ ChatGPT/Codex 桌面版终于上 Linux
OpenAI 发布 ChatGPT 桌面应用 Linux 版，带 ChatGPT Work、Codex、原生安装包和内置浏览器，程序员在 Linux 上终于能用上官方客户端。对开发者仍有少量功能缺口，但方向明确：OpenAI 想让 Codex 出现在你写代码的任何地方。
- 来源: [The New Stack](https://thenewstack.io/openais-chatgpt-desktop-linux/) | [TechCrunch](https://techcrunch.com/2026/08/11/openai-launches-chatgpt-desktop-app-for-linux/)
