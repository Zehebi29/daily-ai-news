**1. OpenAI 把 agent 循环搬进 API：Agents API 正式上线**
- 要点：OpenAI 发布 Agents API（开发者文档站 dev-docs，HN 282pts 热帖），把 Codex 那套"跑命令+拿返回值"的 agent 循环做成云端 API；官方指南里专门给了沙箱方式的网络访问策略——默认放行出站，可选继承模板策略。Simon Willison 第一时间去看的就是沙箱网络那节；评论区一半在吐槽"这正好让数据被程序化偷走"，另一半嫌 Codex 现在连最小任务都要吃 1% 周额度。

**2. Cognition 发布 SWE-2：专挑性价比，Terminal-Bench 2.1 打到 92.8%**
- 要点：Devin 母公司 Cognition 上一代 SWE-1.7 才过一个月就出 SWE-2，宣称"迄今最强编程模型"。FrontierCode 1.1 Main 50.0%（离 Fable 5.1 只差 1 分，但便宜 64%），DeepSWE 1.1 73.0%，Terminal-Bench 2.1 92.8%（超 Fable 5.1 的 91.4%）。技术上的关键点：首次把 RL 扩到"多万亿参数"区间，基座是 2.8T 的 Kimi K3，用一套 RL 算法在单次训练里同时覆盖所有 reasoning-effort 档位，直接抬整个成本-性能前沿。
- 来源：Cognition Blog https://cognition.com/blog/swe-2 · HN 426pts https://news.ycombinator.com/item?id=49645443

**3. 周五工具实测：RTK"省 90% token"被 $1500 实测打脸**
- 要点：RTK（Rust Token Killer）靠压缩终端输出给 agent 省钱，GitHub 79k star、有 X 帖号称能让 Claude Code 省 60% token。Quesma 花了 $1500+、1740 次尝试在 Terminal-Bench 2.1 上对跑：Claude Code(Fable 5.0) 账单只降 5%，OpenCode(DeepSeek V4 Pro) 反而涨 5%；按任务等权平均，DeepSeek 单任务成本涨 17%，两边通过率还各掉 1-2%。JetBrains SkillsBench 同样没测出节省。结论很直白：RTK 自己 README 也承认"少 90% 终端输出 ≠ 省 90% 账单"。同日 HN 还有一篇"九款 coding harness 在你的笔记本上"横评（129pts），评论区直接质疑其 AI 写作痕迹和基准设计。
- 来源：Quesma https://quesma.com/blog/does-rtk-make-ai-coding-cheaper/ · HN https://news.ycombinator.com/item?id=49656471 · 九款横评 HN https://news.ycombinator.com/item?id=49651221
