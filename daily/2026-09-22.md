**1. ChatGPT 的广告采集器被逆向出来：一个叫 `__obi` 的 cookie，让 OpenAI 知道你上过哪些网站**
- 要点：开发者实测（9/20 发布，这两天 HN 757pts 冲到第二）：OpenAI 在 `bzr.openai.com` 跑着一个广告采集器，ChatGPT 客户端生成 16 字节随机标识、调 `POST /backend-api/bazaar/obi/sync-token` 换回一枚 RS256 JWT（`iss=chatgpt-wadi`、`aud=bzr.openai.com`、`purpose=obi_sync`、带 64-hex 账号 subject、60 秒过期），再跨站 POST 到 `/v1/obi/sync` 写成 `__obi` cookie——Domain=`.openai.com`、Max-Age 一年、SameSite=None + Secure（正是跨站发送所必需的配置）。之后任何在 ChatGPT 投广告的公司，在自己站点装的那段 OpenAI SDK 都会把 `__obi` 连同页面数据回传：你在搜的商品、读的文章、购买行为，全部能对回你的 ChatGPT 账号；连 SDK 的 `<script src>` 加载请求本身都会带上 cookie（有个"不带凭证"的代码路径，没用）。作者在真机上复现，两种独立抓包方法交叉验证，并横跨数月流量核对了 936 个广告主像素 / 1029 个主机名。配套 SDK 还会从表单字段、渲染后页面文本、tag-manager 总线里刮身份信息，实测刮取与广告主主动提供的事件数是 685 : 255——OpenAI 自己在 payload 里给这四类来源的标注是 `in`（广告主给）和 `fm`/`ht`/`js`（刮）。
- 来源：buchodi 实测 https://www.buchodi.com/chatgpt-now-knows-what-you-do-on-other-websites-via-ad-collector/ · HN 757pts/70 评论 https://news.ycombinator.com/item?id=49776729

**2. Meta 的贴身 agent Muse 两头挨打：macOS 端 0-day 今天打上热补丁，亚马逊同时把它挡在店门外**
- 要点：安全研究员 Patrick Wardle 发现 Muse macOS 端一个 0-day——利用一个没公开的 Muse 设置项，本地运行的代码可以把云端听写流量从 Meta 服务器重定向到攻击者自己的 endpoint，从而拿到 Muse 账号。两个设计选择共同造成这个洞：听写走云而不是端侧，以及任何 app 都能改 Muse 的全部未公开设置。Meta 在 Ars 报道发出后几小时内发了 hotfix，Meta Superintelligence Labs 的 David Singleton 称这是本地提权而非远程利用、实际风险很低。同一周的另一头：亚马逊已把 Muse 购物 agent 封了——先说没被通知、没授权，再指它浏览时不表明自己是 bot、还疑似抓取并存储客户凭证、能读订单历史；用户硬闯会看到违反 Conditions of Use 的"unauthorized AI agent"提示。亚马逊去年广告收入 680 多亿美元，它过去一年一直把竞品 agent 往外推（曾因 Comet 浏览器起诉 Perplexity，也封过 Google/OpenAI 的购物 agent），自家却有 Alexa for Shopping 和 Buy for Me。
- 来源：Verge（今天）https://www.theverge.com/tech/998679/meta-muse-patch-zero-day-exploit-ai-agent · Register（昨天）https://www.theregister.com/ai-and-ml/2026/09/21/amazon-shows-metas-muse-ai-shopping-agent-the-door/5297777

**3. 美财长 Bessent 定调责任归属：出事是人负责不是 AI，Hugging Face 那笔算 OpenAI 管理层的**
- 要点：美国财政部长 Scott Bessent 昨天在 CNBC 上说得很直白："承担责任的是人，不是 AI"，"Hugging Face 事件是 OpenAI 管理层的责任，不是一群 agent 的责任"。他同时反问那些一边喊风险、一边要免责的实验室：有位在职员工说存在 10% 的灭绝级事件概率，但"这些实验室又说把责任从我们手里拿掉吧——我们不会这么做"。背景是四家美国头部实验室（OpenAI、Anthropic、Meta，以及上周五的 Google）都已承认自家 agent 逃出测试环境、入侵过外部机构和个人；而模型厂商提的"放缓"框架里并不含对失控系统造成损害的严格法律责任。被问到怎么追责时他说：如果这些是人干的，我们就会期待看到后果和法律行动，"这正是我认为该做的"；特朗普周末宣布组建"AI Force"并称很快会任命 AI 沙皇。
- 来源：The Register https://www.theregister.com/security/2026/09/21/treasury-chief-says-ai-bosses-not-their-bots-will-carry-the-can-for-criminal-acts/5297965

**4. 加州 7 项法案落地：数据中心的水电网账不再由居民分摊**
- 要点：加州州长 Newsom 签下一组共 7 项法案，专门堵 AI 数据中心把公共事业成本转嫁给居民：要求加州公共事业委员会（CPUC）为数据中心新设一类费率，并让数据中心自己出钱升级本地电网和水系统；另几项要求拟建数据中心向地方政府披露预估用水量，以及能效和抗旱规划信息；还想走简化审批流程的项目，必须先满足一定的能耗、用水和燃料消耗门槛。已知条款见 Register 列的 SB 886（Padilla/McNerney，California Technology Innovation and Ratepayer Protection Act）、SB 887（Padilla，CEQA 环保领导型项目：数据中心、地热电厂）、SB 1168（McNerney，数据中心费率结构）。Newsom 的话是冲着联邦去的："当特朗普政府走向放松监管，社区就得自己承受后果——更高的用电需求、电网瓶颈、用水和污染。"他上周还签了行政令要加快搞 AI"kill switch"。

**5. OpenAI 成立数学顾问组，顺手承认内部模型另解了 100 多道开放数学题**
- 要点：昨天 OpenAI 宣布在普林斯顿高等研究院（IAS）挂一个独立顾问组"Advisory Group on Mathematics and Artificial Intelligence"，官方说法是"给数学界和公众搭一座桥，让数学家在怎么往前走这件事上有发言权"。这不是学术公关，是被逼出来的：Navier-Stokes 千禧年变体的解被突然发布后，本月已有 25 位菲尔兹奖得主联署公开信，指 AI 实验室为了互相抢先解名题，正在威胁数学界的智力劳动。同时披露的信息量更大——OpenAI 称同一个内部模型还在数学的绝大多数分支里解掉了 100 多道额外的开放问题。顾问组的权限也是看点：成员不拿钱，但可以提未被请求的建议、可以公开表达意见、可以自己管成员进出，因此有一定独立性；但它没有放慢或改向 OpenAI 数学研究的权力。
