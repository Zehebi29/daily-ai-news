**1. "System One 模型"成了一个新物种：前 OpenAI 研究员做的 Jev，24 小时登顶 Vercel 网关采用速度榜**
- 要点：TypeSafe AI（旧金山，9/15 出 stealth，4000 万美元种子轮）的创始人 Diogo Almeida 是 OpenAI 研究员出身、RLHF 的共同发明人，他离开是因为"我们手里握着闪电，却不好用——问题在于我们一直在优化人类语言，而计算机说的是另一种语言"。本周发布的 Jev 是 transformer 但不是 LLM：你给它上下文加一批**预先定义好的带类型问题**（是/否、从给定选项里选一个、在给定刻度上打分），它返回带概率的"校准决策"，约 100 毫秒出结果，输入 $0.042/百万 token、输出 token 免费，TypeSafe 自称在自家工作流评测里比语言模型最快快 194 倍、便宜 445 倍。因为答案集合事先定义，它没有幻觉空间——用他们的话说，Jev 是一个"聪明的 if 语句"，不是聊天框。实测端：Vercel 工程把命令安全分类器从 ChatGPT Luna 5.6 换成 Jev，又快 5–18 倍且更准；上线 AI Gateway 后 24 小时内近 13% 的付费团队在用，是 GPT-5.6 家族的 2 倍、Fable 5.1 的 6 倍多，成为网关史上最快被采用的模型。HN 上生态已经长出来：逆向工程版 jevlike（166pts）、基于 Qwen2.5-0.5B 的 Jev 类模型 kev、System One 计算机操作模型 CUA-S1（82pts）。值得注意的方向性：过去两年大家在做"更会说话"的模型，现在有人开始做"更会判断"的模型，把它当成软件里的一个组件而不是主界面。
- 来源：TechCrunch https://techcrunch.com/2026/09/18/a-new-kind-of-ai-model-from-a-chatgpt-inventor-is-thrilling-developers/ · Vercel https://vercel.com/blog/ai-gateway-jev-model-launch · 深潜 https://flaviocopes.com/jev/

**2. 四家 AI 巨头被消费者集体起诉："合谋放慢 AI"违反反垄断法**
- 要点：Bloomberg Law 9/18 报道，Anthropic、OpenAI、SpaceXAI（马斯克）、Google 被一批付费订阅用户提起集体诉讼，指控四家做了一笔违法交易——集体放慢 AI 发展速度，从而剥夺了订阅者本应获得的产品改进。诉由是《谢尔曼反垄断法》第 1 条（禁止竞争者之间就限制竞争达成协议），原告称合谋的起点是 Anthropic CEO Dario Amodei 发表《We Must Pace the Frontier》后各家高管公开附议（文章主张"限制不受约束的 AI 进展速度"）。原告的措辞很锋利："原告挑战的只是反垄断法禁止的东西：竞争者之间就各自产品改善速度达成的协议。国会没有给这种协议任何豁免。"诉求是集体认证、禁令和确认违法的宣示判决，四家暂未回应。AP、Politico、The Hill、Independent 均已跟进，HN 51pts。这条把 9/13 的 Amodei 长文、9/14 特朗普否掉"踩刹车"串成了第三幕：安全叙事第一次被拉进法庭，且是以"卡特尔"的形式被检验。

**3. GitHub 用 Copilot 把 Copilot 自己的运行时重写成 80 万行 Rust，token 账单约 12 万美元**
- 要点：GitHub 博客（Stephen Toub，9/16）披露：Copilot CLI、Copilot app、Copilot SDK 背后的 agent runtime 原本是 TypeScript / Node.js / V8 技术栈，现在被完整重写成 **80 万行以上生产级 Rust**，AI agent 写了其中大部分代码，分 128 个 PR 增量合入主干而不是最后一次性切换，期间出现的回归都被快速修掉，运行时性能提升数个数量级。规模对比最抓人：这种事以前要一整个团队干一到两年，这次主要由一个开发者用几个月完成，而团队其他成员同期还在继续扩张运行时的能力边界。The Register（9/18）算了一笔账——这轮重写的 token 成本约 **12 万美元**，今天 HN 顶上 36pts/46 评论。The New Stack 把这件事和 Anthropic 自家 Claude Code 的 Rust 重写并列对比：两家都在用自家 agent 重写自家核心基础设施，但流程与护栏完全不同。也就是说 "agent 改造 agent 自己的地基" 从 demo 变成了生产案例。
