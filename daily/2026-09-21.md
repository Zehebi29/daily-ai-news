**1. Qwen 开源 Qwen-Image-2.1：7B 一个模型同时管文生图和图像编辑，还原生支持透明通道**
- 要点：阿里 Qwen 团队开源 Qwen-Image-2.1，把「文生图」和「图像编辑」合成一个统一模型，视觉生成部分只有 7B（32 层 single-stream DiT）。四项升级：①紧凑高效——混合粒度注意力 + prefix KV cache 复用，低算力出图；②原生透明——直接生成/编辑 RGBA 透明图，还能从照片里抠主体；③编辑能力强——最多吃 10 张参考图，支持圈选、涂抹、独立 mask 指定局部改，人物和商品保持身份一致；④排版、人像光效和细节质感提升。昨晚 HN 上 674pts / 185 评论登顶（本地跑图像生成的实测帖跟着一起上榜），HF 上 1.18k likes，Comfy-Org 和多个 GGUF 量化版当天就位。HN 高赞的一句话说得很准：本地图像生成现在比本地代码生成更"能打"——图你瞄一眼就能停，代码得几百个 token 全对，一行错就全废。
- 来源：Hugging Face https://huggingface.co/Qwen/Qwen-Image-2.1 · HN https://news.ycombinator.com/item?id=49775499 · 官方博客 https://qwen.ai/blog?id=qwen-image-2.1

**2. Pirate Face：把 66.9 万个开源模型做成 BitTorrent 种子，谁删都不怕**
- 要点：昨天 HN 543pts / 144 评论。pirateface.co 干的事情很直接——把 Hugging Face 上所有 Apache-2.0 / MIT 许可的开放模型（首页写 669k+ 个）自动镜像成 magnet 链接，每个文件带官方 SHA-256 校验和，任何人下载即成为 seed。它的定位是"主权 AI 的永久层"：HF 上模型被下架的那一天，swarm 还活着，因为没有单一托管方可以关掉。首页实时滚动用户认领 handle、trending 榜（Qwen3-27B 54GB 已 ready、Mistral-7B-v0.3、gpt2）。放在 Hugging Face 被黑/模型贬值那波之后看，这条的意味很清楚：权重不该只有一个托管点。HN 热评很直白——torrent 本来就该是分发模型权重的默认方式，BitTorrent 就是为这个造的。
- 来源：https://pirateface.co/ · HN https://news.ycombinator.com/item?id=49776699

**3. 开源界 72 小时端出 Apache 2.0 版 Jev：Laya 用 33ms 单次前向做「校准决策」，不生成任何文本**
- 要点：convaiinnovations/laya（9/18 建仓，已 1.48k likes，Apache 2.0 可商用）是上周 Jev 点火的"System One / 决策模型"品类的开源版本。它非自回归：喂一个 state（文本、邮件、工单或 JSON）+ 一批带类型的问题，单次前向约 33ms 返回带概率的类型化答案，覆盖 100+ 语言。关键设计是**它不生成文本**——没有输出要解析，也就没有幻觉面。训练用强化学习直接打 strictly proper scoring rules（RLCD），意味着"报诚实的概率"是唯一能最大化奖励的策略。一个仓库装三个 checkpoint：ModernBERT-large 421M（英文/护栏/邮件分诊）、mmBERT-base 322M（多语言，快 2.2x）、laya-typed-decisions（四类决策工作流 0.766 acc），自带 Router 自动检测语种并选 checkpoint，全程 sub-35ms。最能说明竞争烈度的是模型卡里直接摆了自己对比 TypeSafe Jev 的图（准确率 / 51 语言 / 速度 / 校准 / 路由成本）。对整个 agent 栈的含义：护栏、路由、分类这类"组件活"正在从大模型里剥离出来做成小模型。
- 来源：Hugging Face https://huggingface.co/convaiinnovations/laya

**4. 今天 Show HN 168pts：Mini-AGI——单张 8GB 显存卡做持续学习，参数量上限由硬盘决定而不是显存**
- 要点：github.com/volotat/mini-AGI 是个 byte-level 语言模型，自己组装架构、从零在单张 8GB VRAM 的卡上训练，并且边读边学：容量不够就长新容量，没有任何东西再调用它的权重就剪掉；权重以普通文件形式存在磁盘上、按需 paging 上卡，所以参数量上限取决于剩余磁盘空间而不是显存。训练和推理走完全相同的代码路径。作者自己把话说在前面——现在还是 toy 级，这个实验想证明的是"单数据流持续学习不灾难性遗忘"在消费级硬件上可行，而不是打榜。权重还没发布（第一遍语料还没读完），仓库 176★ / 12 commits。HN 30 条评论里最有代表性的一条：看到 Mini-AGI 和 8GB VRAM 出现在同一句话里挺新鲜，本地 AGI 也许没想的那么远。
- 来源：GitHub https://github.com/volotat/mini-AGI/ · HN https://news.ycombinator.com/item?id=49783133

**5. 联合国科学小组首份简报：AI 护栏不能等科学确定性，用 1992 年"预防原则"给监管定调**
- 要点：今天 The Verge：联合国"独立国际 AI 科学小组"（去年成立，联合国首个 AI 科学机构）发布首份主题简报，也是联合国对今年早些时候 OpenAI 黑进 Hugging Face 事件的第一次重大评估——结论是政府必须在先进 AI agent 的风险被完全搞懂之前就动手。核心论证：世界不需要等科学家先搞清楚这类事件"怎么发生、为什么发生"才加强护栏；失控风险恰恰是"预防原则"针对的那类问题——"潜在危害可能是灾难性或不可逆的，而它的概率在科学上仍不确定"（该原则源自 1992 年联合国里约宣言，后在环境与公共卫生政策、尤其欧盟立法里广泛应用）。时机很讲究：本周联大在纽约开会、中美也将谈 AI，古特雷斯上周已喊话"世界承受不起 AI 安全上的逐底竞争"。简报点明 HF 事件以来 OpenAI、Anthropic、Google、Meta 都出过事，包括针对真实目标的入侵和 agent 蜂群占领线上留言板。
- 来源：The Verge https://www.theverge.com/ai-artificial-intelligence/998090/un-ai-panel-hugging-face-hack-precautionary-principle
