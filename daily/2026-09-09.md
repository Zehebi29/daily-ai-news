# 2026-09-09 AI资讯

今日要点（周三·Agent/工程落地）

**1. OpenAI 公布 Navier-Stokes 完整证明，NYU 数学家指控其「手段不干净」**
- 要点：OpenAI 公布千禧年难题 Navier-Stokes 存在性与光滑性的完整证明——据 OpenAI 称由未发布的新一代模型完成，一周烧掉 3000 亿输出 token（按 Astra 现价约 $2250 万算力）；NYU 教授 Tristan Buckmaster（与 Anthropic 数学家 Levent Alpöge 合作近一年，全程用 Claude 和 Codex/GPT-5.6 Sol）同日发文指控 OpenAI 在他们成果公开前抢先下手，问 OpenAI 首条 prompt 何时发出、模型是否看过他们 Codex 里的草稿，均未获正面回答，还因「与 Anthropic 的竞争关系」把 Alpöge 排除在共同署名外。Science 今天发文复盘这场争议。
- 来源：HN 1287pts 🔗https://news.ycombinator.com/item?id=49613262 · Simon Willison 🔗https://simonwillison.net/2026/Sep/8/on-navier-stokes/ · TechCrunch 🔗https://techcrunch.com/2026/09/08/openai-fought-dirty-on-career-making-math-problem-says-nyu-mathematician/ · Science 争议复盘(HN 136pts) 🔗https://news.ycombinator.com/item?id=49624163

**2. Anthropic 研究员辞职公开警告：两家巨头都在「拿命赌博」**
- 要点：前 OpenAI、现 Anthropic 的研究员 Jacob Coxon 今天宣布辞职，称 Anthropic 和 OpenAI 都「正在冲向能自我改进的超级智能」，并警告「这些很快会成为能黑掉任何东西、一夜颠覆任何领域的超人类系统」；Anthropic 对齐负责人 Evan Hubinger 公开背书：真的相信 AI 有 >10% 概率十年内杀死全人类，且「目前没有解决超级智能对齐的方案、也没有清晰的路线」，该帖浏览超 1000 万次。Politico 与 BBC 今天均报道。
- 来源：HN 601pts 🔗https://news.ycombinator.com/item?id=49619227 · Politico 🔗https://www.politico.eu/article/anthropic-openai-researcher-jacob-coxon-warns-ai-could-kill-humans/ · BBC 🔗https://www.bbc.co.uk/news/articles/ckgwy1k42w4o

**3. DeepSeek V4.1 Flash：新架构原生多模态，全面超 V4 Pro，明天中午上线**
- 要点：DeepSeek 今日宣布 V4.1 Flash——新模型架构、原生多模态，官方称性能/成本/速度/任务完成时间全面超过 V4 Pro；beta 已开放（模型名 `deepseek-v4.1-flash-expires-on-0910`，当前按 v4-flash 价、20 并发限制），正式上线定在明天（9/10）12:00 北京时间，同步调价：非高峰 $0.003/M 输入缓存命中、$0.15/M 未命中、$0.6/M 输出，高峰翻倍；V4.1 Pro 发布前，所有 Pro 请求将路由到 V4.1 Flash 并按 Flash 价计费。
- 来源：HN 85pts 🔗https://news.ycombinator.com/item?id=49624603 · beta 公告(HN 21pts) 🔗https://news.ycombinator.com/item?id=49607094

**4. Harness 为 AI agent 流量重写 Git 仓库：PR 洪峰把评审逼成瓶颈**
- 要点：Harness 外场 CTO Martin Reynolds 谈 AI 编程 agent 带来的 PR 洪峰：早期 Copilot 试点时 1.5–2 倍的新代码已把测试团队压垮，现在客户普遍 10 倍、个别号称 50 倍，代码评审成了最大瓶颈，部分企业干脆提高风险容忍度、放更多代码直接进生产；Harness 为此重写了 Code Repository 并上线新版 AI Code Review（GitHub 8/17 近 8 小时宕机也是背景）。典型周三工程向内容。
- 来源：The New Stack 🔗https://thenewstack.io/harness-ai-code-review/

**5. Cognition（Devin）融 $2B、估值 $48B：AI 编程不是赢家通吃？**
- 要点：Devin 开发商 Cognition 宣布完成 $2B 融资、估值 $48B（a16z/Accel/Founders Fund/General Catalyst/Avenir 领投），距 5 月 $26B 那轮仅 4 个月；年化收入 run-rate 从 $4.92 亿涨到 $9 亿，估值倍数比 Cursor 谈 $50B 时还高。TechCrunch 解读为 VC 押注 AI 编程赛道容得下多家巨头，并点出 Cursor 卖身 SpaceX 主因是算力受限——Cognition 租 Nvidia 集群一年成本数亿美元，同样面临算力天花板。
- 来源：TechCrunch 🔗https://techcrunch.com/2026/09/08/cognition-hits-48b-valuation-signaling-investors-believe-ai-coding-is-far-from-a-winner-take-all-market/
