# 2026-08-10 AI资讯（周一·模型发布/开源周报）

## 1️⃣ Claude Code Auto 模式默认开启
Anthropic 官宣 8月14号起，Claude Code 的 auto 模式成为大部分套餐的默认权限模式。以前让 AI 写代码每步都要人工点允许，现在默认自己动手。Simon Willison 点评这是 Anthropic 对自家模型信任度的一次豪赌，省事是真省事，但出错率也上来了，该盯还是得盯。
- 来源: [Simon Willison](https://simonwillison.net/2026/Aug/8/auto-mode/) | [HN 17pts](https://news.ycombinator.com/item?id=49227253)

## 2️⃣ OpenAI 因安全担忧暂缓 Astra 模型
OpenAI 承认正在放缓模型 Astra 的开发进度，内部测试发现它在网络安全方面的能力越过了某条线——还没有哪个 AI 到过这个水平。外媒分析 OpenAI 担心模型被用于攻击性用途，宁可晚点发也不冒险。上周刚传出它解开十个数学难题，这周又因为太强被扣下，反转够戏剧。
- 来源: [The Guardian](https://www.theguardian.com/technology/2026/aug/08/openai-astra-security-concerns) | [HN 8pts](https://news.ycombinator.com/item?id=49225124)

## 3️⃣ Cloudflare 发布 Kitesurf：AI Agent 专用浏览器
Cloudflare 发布跑在 Workers 上的无状态浏览器 Kitesurf，专为 AI agent 设计，可大规模扩展、成本低，HN 217分。给 agent 原生上网环境，渲染交互全在云端，等于把浏览器变成 AI 基础设施。
- 来源: [Cloudflare Blog](https://blog.cloudflare.com/kitesurf/) | [HN 217pts](https://news.ycombinator.com/item?id=49208393)

## 4️⃣ 五巨头背书 Vercel Agent Plugins 标准
OpenAI、AWS、Cursor、GitHub、微软五家联合支持 Vercel 推的 Agent Plugins 标准，统一打包 AI 技能和 MCP 服务器的格式。五家竞争对手坐下来谈同一个标准在 AI 圈真不多见，对开发者来说以后换生态也省心。
- 来源: [The New Stack](https://thenewstack.io/agent-plugins-open-standard/) | [HN 24pts](https://news.ycombinator.com/item?id=49203443)

## 5️⃣ SAP 冻结招聘出差：AI 太烧钱
SAP 宣布继续冻结大部分招聘和出差，理由是 AI 太烧钱，公司说要「在花钱上保持自律」。但冻结不包含 AI 相关投入——省下的钱全力押注 AI，传统业务先靠边站。这种砍传统预算、加码 AI 的操作，后面估计很多大公司都会学。
- 来源: [404 Media](https://www.404media.co/software-giant-sap-stops-most-travel-and-hiring-because-of-ais-soaring-cost/) | [HN 93pts](https://news.ycombinator.com/item?id=49229412)
